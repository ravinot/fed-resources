# Contributing

This is my personal list, but if you've got a link that belongs here, I'd like to see it.

## Adding a link

- Make sure it's not already in the list.
- Add it under the right section in `README.md`, alphabetically within that section.
- Format: `- [Name](https://example.com) — short, one-line description.`
- Check the link actually works before opening a PR.

## Reporting a dead link

If something's broken, moved, or turned into a parked domain, open an issue (or just send a PR removing it) and I'll sort it out.
